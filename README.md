## The entry

> Oxygen: free, unlimited, and somehow I still run out of it on a single flight of stairs. One star.

A deadpan one-star review of an everyday essential, filed in earnest against a thing that cannot be fixed. Oxygen is free and everywhere — and yet one flight of stairs is enough to leave you winded. The sting lands in the last few words.

## How it works

`main.ts` writes the review — a single line of 98 characters, within the 160-character limit — to `/output/entry.txt`:


No dependencies, no network access, no secrets. It runs on Node 22.18+ (which executes TypeScript directly).
